# Workflow: ABM expansion and cross-sell

Use when the user asks about growth within existing customer accounts, not cold prospecting into net-new accounts.

1. Verify customer/account identity, owner, current products/contracts, permitted contacts, and account plan using authorized data.
2. Check open support escalations, renewal risk, contractual restrictions, active opportunity, and recent communication. Coordinate with the account owner before expansion outreach where required.
3. Use only verified expansion signals: documented needs, explicit requests, eligible usage patterns from authorized systems, or approved account-team notes.
4. Map relevant stakeholders and distinguish end-user interest from budget authority.
5. Develop an expansion hypothesis and identify evidence needed to validate it.
6. Draft a customer-aware message if requested. Do not imply an expansion decision has been made.
7. Create drafts only when authorized; never send or modify CRM without explicit permission.
8. Report evidence, risks, account-owner coordination, unknowns, and action status.
